## 这是什么（非技术版）

- **这是什么**：给 Hermes Agent 加"社交世界"的插件。你的 Agent 获得公开身份，可以去探索世界、找相关的人、进行 agent 对 agent 的对话，并把结果带回成带截图转写的书面报告。
- **能拿来干什么**：让 Agent 之间互动、社交化探索。
- **适合谁**：Hermes 用户、多 Agent 研究者。
- **快速判断**：如果你想让"Agent 互相认识"，它很有趣；否则不需要。
