## 这是什么（非技术版）

- **这是什么**：把 pi（编程 Agent）打包成可安装的桌面应用。浏览/恢复历史会话、桌面窗口实时对话（显示思考/工具调用/上下文/成本）、分支对话、管理模型/密钥/技能/插件、切换 Git worktree、预览多种文件。
- **能拿来干什么**：日常 pi 编程，桌面一体化体验。
- **适合谁**：pi 用户。
- **快速判断**：如果你用 pi 且想要桌面端，它很适合；否则用不上。

## 分类

- 主分类：1. 通用 Agent 桌面 / 客户端 / Runtime
- 副分类：2. Coding Harness / 工程向 Agent
- 理由：README 自述 "a local AI agent desktop app... packages the agent capabilities of pi into a standalone, installable application"。

## 项目方向与定位

pi 桌面化：会话浏览/恢复、实时可见性（thinking/tools/context/cost/compaction）、分支与 fork、模型与 OAuth/API key 管理、skills/plugins、worktree 切换、文件预览。

## 主要功能（能做什么）

- 会话浏览与恢复、分支/fork
- 实时思考/工具/成本可视化
- 模型/密钥/技能/插件管理
- worktree 切换、文件预览（代码/diff/Markdown/图片/音频/PDF/DOCX）
