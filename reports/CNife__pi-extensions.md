## 这是什么（非技术版）

- **这是什么**：一个 pi Agent 的扩展集。分三层：产品层（可发布 npm 包 @cnife/pi-*）、个人层（随 pi 分发）、退役层（停用插件存档）。
- **能拿来干什么**：给 pi 加扩展能力。
- **适合谁**：pi 用户。
- **快速判断**：如果你用 pi 且需要扩展，它值得看；否则用不上。
