## 这是什么（非技术版）

- **这是什么**：一套"像小书一样"的免费教程，从零拆解大模型、Agent 与 Skill：先懂模型怎么工作，再看模型怎么长出手脚（工具/记忆/规划/协作），最后学会把经验写成可复用的技能手册。
- **能拿来干什么**：系统学习 AI/Agent 底层原理、写作参考。
- **适合谁**：想从原理层面理解 Agent 的开发者、学习者。
- **快速判断**：如果你要系统补 Agent 底子，它很好；如果只想用现成工具，不需要。

## 分类

- 主分类：6. 特定领域 / 其他（教育/教程）
- 副分类：2. Coding Harness / 工程向 Agent（教学主题）
- 理由：README 自述"这个仓库按三套系列文章组织，像一本从底层原理到工程实践的小书"。

## 项目方向与定位

三套系列：从零理解大模型（Token/Embedding/Attention/Transformer/训练/推理/Scaling Law/MoE 等）、从零理解 Agent（工具/记忆/规划/协作）、从零写好 Skill（可复用工作手册）。推荐阅读顺序：模型 → Agent → Skill。

## 主要功能（能做什么）

- LLM 底层机制系列（01-next-token → 推理/计费/思考模式/MoE）
- Agent 原理系列（工具调用/记忆/规划/协作）
- Skill 编写系列
