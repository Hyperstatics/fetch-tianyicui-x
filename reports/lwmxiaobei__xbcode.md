## 这是什么（非技术版）

- **这是什么**：一个"能从头读到尾"的终端 AI 编程助手。用 OpenAI SDK 和 Ink 构建，流式输出、执行本地工具、持久任务、skills、MCP、轻量多 Agent 团队；定位是紧凑、可改写的替代品。
- **能拿来干什么**：日常终端 AI 编程，学习/改造一个 Agent 实现。
- **适合谁**：开发者、想读透 Agent 源码的人。
- **快速判断**：如果你想要"小而全、可 hack"的 Agent，它很适合；否则功能更全的 Agent 更省事。
