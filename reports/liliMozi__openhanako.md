## 这是什么（非技术版）

- **这是什么**：一个"有记性、有性格的 AI 助手"。不用写配置文件，它会记住你说过的事，帮你操作电脑、浏览网页、管理日程，还能多个 AI 一起协作；图形界面完整，专门为不写代码的普通办公者设计。
- **能拿来干什么**：日常办公助理（文件/搜索/截图/日程）、让 AI 主动干活、用"人格"定制沟通风格。
- **适合谁**：普通上班族、不想碰命令行的用户；开发者也可深度使用。
- **快速判断**：如果你想要"像同事一样有记性、好沟通"的本地 AI 助理，它很对路；如果只是要一个聊天框，其他客户端更轻。

## 分类

- 主分类：1. 通用 Agent 桌面 / 客户端 / Runtime
- 副分类：4. 记忆 / 上下文 / 知识管理（记忆系统为核心卖点）
- 理由：README 自述"有记忆、有性格，会主动行动，还能多 Agent 在你的电脑上一同工作"，明确面向非 coder。

## 项目方向与定位

弥合普通人与 Agent 的缝隙：不做"只属于命令行"的工具，强化 Agent 的"人味"（记忆 + 人格）与办公场景工具性。记忆系统"近期的事记得非常牢固"；Agent 即文件夹（人格/记忆/备份方便）；默认对社区 SKILLS 做严格审核，也允许 Agent 自主学习新技能。

## 主要功能（能做什么）

- 记忆系统（主记忆方案 + 自研强化，自述待优化）
- 人格模板/自定义人格文件，Agent 之间分离清晰
- 工具：文件读写、一次性命令/持续终端会话、网页浏览、搜索引擎/浏览器后端、截图/长截图、媒体预览
- SKILLS：兼容社区生态 + 自主从 GitHub 安装 + 自主编写新技能（默认严格审核）
- 图形界面 + server-first CLI；多 Agent 同机协作

## 架构设计

```text
core/      核心运行时
cli/       终端入口
desktop/   图形客户端
hub/       技能/插件枢纽
plugins/ + PLUGIN_SDK.md  插件体系
packages/ lib/ examples/ build/
```

## 实现思路与核心逻辑

- 以"人"为中心：记忆 + 人格 + 主动性，降低使用门槛
- Agent 即文件夹：人格/记忆/配置随文件夹迁移，便于备份与隔离
- 技能治理：默认严格审核社区 SKILLS，平衡开放与安全

## 亮点

- 5.7k stars，定位差异化（面向非开发者，中文语境友好）
- 记忆 + 人格双卖点，在 Agent 客户端中少见
- 图形界面完备 + 插件生态 + 主动学习技能

## 局限与风险（可选）

- 项目较新，记忆系统自述"有待优化"
- 功能多，稳定性与安全（自主装技能）需实践检验
