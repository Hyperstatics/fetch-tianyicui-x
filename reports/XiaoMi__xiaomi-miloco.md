## 这是什么（非技术版）

- **这是什么**：小米开源的"全屋智能管家"。通过米家摄像头看和听家里发生了什么，用大模型理解，主动判断要不要开灯、提醒吃药、识别家人并个性化服务。
- **能拿来干什么**：搭建家庭自动化 Agent；把"模糊的长期目标"（如每天锻炼）拆成可执行的家庭任务。

## 项目方向与定位

Miloco 2.0 重构为 OpenClaw 插件：以米家摄像头音视频为全模态感知入口、MiMo 大模型为大脑，编排全屋设备做**主动式**智能（通用常识、身份识别、家庭记忆、家务任务、主动干预）。定位是"家庭场景的 Agent 落地样板"。

## 主要功能（能做什么）

- 通用常识：无预设规则自动识别危险（儿童玩刀、老人跌倒）并分级告警
- 身份识别：人脸/体态融合识别家庭成员，个性化服务
- 家庭记忆：从感知与交互中提炼习惯与偏好
- 家务任务：条件自动化 / 定时提醒 / 习惯追踪等复杂长期任务
- 家庭仪表盘（Web）、Hermes Agent 兼容层、多模型运行时

## 架构设计

```text
backend/  感知与推理后端
web/      家庭仪表盘
cli/      命令行诊断
knowledge/ 常识/知识
plugins/  插件
```

## 实现思路与核心逻辑

- 全模态感知：摄像头音视频 → 事件 → 大模型推理
- 主动式决策：观察 → 推理 → 在"恰当时机"干预
- 反馈闭环：用户口头纠正即"养育"自己的 Miloco（偏好记忆调整）
