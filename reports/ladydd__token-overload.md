## 这是什么（非技术版）

- **这是什么**：一个"AI 省钱编排器"。读文件、写代码、跑测试等占 80%+ token 的脏活交给便宜弱模型（价差约 16 倍），强模型只做规划（目标→任务卡）和验收（看摘要判断 pass/rework）；中间用程序自动验证，强模型省约 60% token、总成本省约 70%。
- **能拿来干什么**：降低 AI 编程成本。
- **适合谁**：开发者、成本敏感团队。
- **快速判断**：如果你在意 token 成本，它很有价值；否则不需要。

## 分类

- 主分类：2. Coding Harness / 工程向 Agent（成本优化）
- 副分类：3. 多 Agent 编排 / 协作系统
- 理由：README 自述"强模型负责规划和验收，弱模型负责读文件、写代码、跑测试、试错——强模型 token 省约 60%，总成本省约 70%"。

## 项目方向与定位

分层执行：强模型规划/验收、弱模型执行、程序验证兜底；53 tests。
