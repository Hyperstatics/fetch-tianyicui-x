## 这是什么（非技术版）

- **这是什么**：一个"开箱即用、能一直跑"的 AI 编码 Agent 运行时。文件编辑、Shell 执行、联网、记忆、技能、子代理、MCP、Hooks、远程服务、Telegram 控制、定时自动化都是第一等能力；本地助手或远程常驻 worker 都行。
- **能拿来干什么**：本地编码助手、远程 Agent 服务、自建 Agent 工作流。
- **适合谁**：开发者、想"拿到就能用"的 Agent 用户。
- **快速判断**：如果你不想先搭框架、直接要能用的 Agent 运行时，它很适合；否则需要更定制化的框架。
